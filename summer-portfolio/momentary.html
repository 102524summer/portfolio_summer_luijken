01Context

Momentary is a social diary and notes hybrid. Part private notebook, part something you can share when you want to.

It began as a Flutter prototype. Then I moved it to React Native with Expo, and gave it its own PHP REST API to talk to.

a diary that other people can read, if you want

the brief

02Research

Before any code, the questions were about behaviour: how people write things down, and what they are willing to show.

starting questions

  • What is a diary when other people can read it?
  • How fast can you capture a thought?
  • What stays private by default?
  • Notes or posts, or both?

05Build

The app is built with React Native and Expo. A PHP REST API sits behind it and handles the data. Moving from Flutter to React Native meant rebuilding screens, but the structure carried over.
